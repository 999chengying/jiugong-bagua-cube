# 顺逆规则：帝5路径的完整大法

## 一、顺行规则

### 目标序列
按帝5序列循环：
3 → 5 → 9 → 5 → 6 → 5 → 3

### 候选选择
在邻域中找目标数的所有候选。

### 优先级
1. 方向惯性最大（与上一步方向的内积最大）
2. 距离最近
3. 字典序最小

### 效果
顺行九圈，螺旋远离中宫，距中宫约41。

## 二、逆行规则

### 目标数
直接锁定为5（不按+3规则）。

### 候选选择
在邻域中找值为5的所有候选。

### 优先级
1. 距中宫(3,3,3)最近
2. 方向惯性辅助
3. 字典序最小

### 效果
逆行二十步，精确回归中宫(3,3,3)，距中宫0.00。

## 三、关键发现

### 归中的关键
逆行目标必须是5，不随链条走。

之前失败的原因：
- 逆行目标仍按+3规则算，目标数不是5；
- 导致无法归中，陷入局部最优。

### 修正后
- 逆行目标锁定5；
- 每一步都在找5；
- 逐步归中，无一后退。

# 精一之道：逆行归中的心法与算法

## 一、什么是精一之道

《尚书·大禹谟》：

> 人心惟危，道心惟微；惟精惟一，允执厥中。

精一之道 = 惟精惟一 + 允执厥中

| 精一之道 | 逆行规则 |
|---|---|
| 惟精 | 每一步精确锁定5 |
| 惟一 | 目标唯一，不随链条走 |
| 允执厥中 | 逐步归中，最终(3,3,3) |

## 二、顺行 vs 逆行

| 顺行 | 逆行 |
|---|---|
| 按序列走 | 锁定5 |
| 方向惯性最大 | 距中宫最近 |
| 复杂路径 | 直线归中 |
| 螺旋远离 | 线性收敛 |

顺行是分别，逆行是归一。
分别则复杂，归一则简单。

## 三、逆行归中的线性规律

实验数据（顺行圈数 vs 逆行步数）：

| 顺行圈数 | 距中宫 | 逆行步数 | 步数/距离 |
|---:|---:|---:|---:|
| 1 | 8.49 | 4 | 0.471 |
| 5 | 24.49 | 12 | 0.490 |
| 10 | 45.96 | 22 | 0.479 |
| 15 | 66.63 | 32 | 0.480 |
| 20 | 88.05 | 42 | 0.477 |

线性拟合：

步数 ≈ 0.48 × 距离

即：

每步减少距离 ≈ 2.08

归中速度恒定，与距离无关。

## 四、为什么线性

每步坐标移动是2的倍数，向中宫方向的投影约2.08。

归中步数 = 距中宫距离 / 2.08

这是一个线性时间算法：
- 距离越远，步数越多；
- 但每步效率恒定；
- 没有加速，没有减速。

## 五、精一之道的算法

```python
def find_next_ni(current_pos, prev_dir):
    """
    逆行规则：精一之道。
    1. 在邻域中找值为5的候选
    2. 选距中宫(3,3,3)最近的
    3. 若距离相同，选方向惯性最大的
    """
    candidates = [p for p, v in neighbors(current_pos) if v == 5]
    if not candidates:
        return None
    best = None
    best_score = None
    for p in candidates:
        d = geo_dist(p)          # 距中宫距离
        if prev_dir:
            dot = sum(prev_dir[i] * (p[i] - current_pos[i]) for i in range(3))
        else:
            dot = 0
        # 距离最近优先，方向惯性辅助
        score = (d, -abs(dot), p)
        if best_score is None or score < best_score:
            best_score = score
            best = p
    return best
```

核心只有三行：
1. 找值为5的候选；
2. 选距中宫最近的；
3. 距离相同选方向连续。
