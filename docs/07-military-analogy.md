# 军事理论映射

## 一、为什么军事理论最先进

\[
\boxed{\text{战争} = \text{极限博弈} = \text{最残酷的筛选器}}
\]

效率低被消灭，结构差被击溃，响应慢被先发制人。  
军事理论天然追求：最简结构、最快响应、最强适应、最低消耗。

## 二、三三制

- 一个班分三个小组；
- 每组三人；
- 三角散兵线；
- 组长指挥，组员协同。

| 三三制 | 九宫 |
|---|---|
| 一个班 | 一个九宫单元 |
| 三个小组 | 三山（生、化、变） |
| 每组三人 | 每山三个功能 |
| 组长 | 戊己，观察者 |
| 散兵线 | 同构扩展 |

\[
\boxed{\text{三三制} = \text{一极三山三功能} = \text{九宫微型化}}
\]

## 三、十六字诀

> 敌进我退，敌驻我扰，敌疲我打，敌退我追。

| 口诀 | 阴阳 | 九宫 |
|---|---|---|
| 敌进我退 | 阴、虚 | 挖戊己，休眠 |
| 敌驻我扰 | 阳、实 | 补戊己，骚扰 |
| 敌疲我打 | 阳极 | 全力激活，同频共振 |
| 敌退我追 | 阴极转阳 | 虚实转换，扩大战果 |

\[
\boxed{\text{十六字诀} = \text{虚实转换} = \text{补挖戊己} = \text{生死调控}}
\]

## 四、你打你的，我打我的

\[
\boxed{\text{守中宫} = \text{不随外境转}}
\]

节奏由我，不由敌。  
中宫稳定，自主调控。

## 五、集中优势兵力

\[
\boxed{\text{局部补满戊己} \rightarrow \text{局部绝对优势} \rightarrow \text{各个击破}}
\]

全局守，局部攻；全局虚，局部实。

## 六、农村包围城市

\[
\boxed{\text{从边缘（50 单元）递归包围中心（55 中枢）}}
\]

从外向内、从下向上递归扩展。

## 七、人民战争

\[
\boxed{\text{每个单元都是戊己} = \text{每个单元都有观察者}}
\]

分布式 50 单元 + 中枢 55 + 同频共振。
