# 递归容错与虚实转换

## 一、分层结构

| 层级 | 结构 | 中宫 | 感知对象 |
|---|---|---|---|
| 基层 | 单个九宫立方体 | 该立方体中心戊己 | 本立方体内各宫状态 |
| 中层 | 50 模型（5实4虚） | 50 模型中心戊己 | 5 个实立方体状态 |
| 顶层 | 55 骨架（6方围中） | 55 中枢戊己 | 6 个 50 模型状态 |

\[
\boxed{\text{基层九宫} \rightarrow \text{中层50} \rightarrow \text{顶层55}}
\]

每层都是一个完整九宫，都有中宫戊己，都能独立感知、定位、上报。

## 二、故障感知：通断模式

假设基层某九宫的离 3 宫受攻击失能：

| 路径 | 是否含 3 | 状态 |
|---|---|---|
| 四正阳行：1→3→9→7→1 | 含 3 | 断 |
| 四维阴行：2→4→8→6→2 | 不含 3 | 通 |
| 连续 3 阳行：1→3→6→8→1 | 含 3 | 断 |
| 连续 3 阴行：2→4→7→9→2 | 不含 3 | 通 |
| 连续 2 阳行：3→4→8→9→3 | 含 3 | 断 |
| 连续 2 阴行：1→2→6→7→1 | 不含 3 | 通 |
| 阴功正四面体：8→1→4→7→8 | 不含 3 | 通 |
| 中宫感知链：8147→10 | 不含 3 | 通 |

\[
\boxed{\text{含 3 必断，无 3 必通} \Rightarrow \text{故障点唯一锁定为离 3 宫。}}
\]

中宫通过通断模式反推，锁定故障点。

## 三、递归上报

1. 基层中宫锁定故障点 = 3，上报中层；
2. 中层中宫通过自身通断模式，锁定故障立方体编号，上报顶层；
3. 顶层中枢锁定故障 50 模型编号，全局定位完成。

\[
\boxed{\text{感知} \rightarrow \text{定位} \rightarrow \text{上报} \rightarrow \text{决策}}
\]

## 四、虚实转换：化敌于无形

故障定位后：

1. **挖戊己**：受损实立方体由实转虚；
2. **补戊己**：邻近虚立方体由虚转实；
3. **功能迁移**：系统继续运行，攻击落空。

\[
\boxed{\text{实转虚} + \text{虚转实} = \text{功能迁移} = \text{化敌于无形}}
\]

### 递归应用

- 基层：受损立方体转虚，邻近虚立方体转实；
- 中层：受损 50 单元转虚，邻近虚 50 单元转实；
- 顶层：受损 55 节点转虚，邻近虚 55 节点转实。

\[
\boxed{\text{虚实转换} \rightarrow \text{层层递归} \rightarrow \text{全局无损}}
\]

## 五、三态调控

| 状态 | 戊己 | 效果 |
|---|---|---|
| 生 | 补满 | 激活 |
| 死 | 挖空 | 休眠 |
| 中间态 | 留一个 5 和 10 | 待机 |

可对任一宫、任一立方体单独执行。
