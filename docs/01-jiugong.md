## 剪枝规则

| ID | 名称 | 条件 | 动作 |
|---|---|---|---|
| R1 | 父母退位 | 极点 1,2,3,4 含 9；或 6,7,8,9 含 1 | 剔除 |
| R2 | 空形剔除 | 四点共面 | 剔除或标记空 |
| R3 | 重复数剔除 | 有重复 | 剔除 |
| R4 | 中宫剔除 | 含 5 | 剔除 |
| R5 | 对称归约 | 体对角等价 | 合并 |
| R6 | 生成优先 | 含差 5 对 | 高优先 |
| R7 | 体对标记 | 含和 10 对 | 标记变位 |
| R8 | 恒形保留 | 正四面体 | 优先保留 |
| R9 | 逐圈剪枝 | 每圈先去父母 | 逐圈过滤 |
