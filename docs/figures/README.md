# 图目录说明

本目录用于放置九宫八卦立方体的示意图。

## 建议图目

1. 九宫图（平面）
2. 立方体八顶点坐标图
3. 六表面与六对角截面
4. 二十四山圆序图
5. K=5 回文五圈图
6. K=9 双正四面体图
7. 天地之数 55 六方围中图
8. 大衍之数 50 十字风车图
9. 四象结构图（24/28/32/36）
10. 帝5行踪路线图

## 格式

- 优先 SVG，便于缩放；
- 次选 ASCII，便于手机查看；
- 命名规范：`fig-01-jiugong.svg`、`fig-02-cube.svg` 等。
