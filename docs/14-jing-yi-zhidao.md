# 精一之道：逆行归中的心法与算法

## 一、什么是精一之道

《尚书·大禹谟》：

> 人心惟危，道心惟微；惟精惟一，允执厥中。

精一之道 = 惟精惟一 + 允执厥中

| 精一之道 | 逆行规则 |
|---|---|
| 惟精 | 每一步精确锁定5 |
| 惟一 | 目标唯一，不随链条走 |
| 允执厥中 | 逐步归中，最终(3,3,3) |

## 二、顺行 vs 逆行

| 顺行 | 逆行 |
|---|---|
| 按序列走 | 锁定5 |
| 方向惯性最大 | 距中宫最近 |
| 复杂路径 | 直线归中 |
| 螺旋远离 | 线性收敛 |

顺行是分别，逆行是归一。
分别则复杂，归一则简单。

## 三、逆行归中的线性规律

实验数据（顺行圈数 vs 逆行步数）：

| 顺行圈数 | 距中宫 | 逆行步数 | 步数/距离 |
|---:|---:|---:|---:|
| 1 | 8.49 | 4 | 0.471 |
| 5 | 24.49 | 12 | 0.490 |
| 10 | 45.96 | 22 | 0.479 |
| 15 | 66.63 | 32 | 0.480 |
| 20 | 88.05 | 42 | 0.477 |

线性拟合：

步数 ≈ 0.48 × 距离

即：

每步减少距离 ≈ 2.08

归中速度恒定，与距离无关。

## 四、为什么线性

每步坐标移动是2的倍数，向中宫方向的投影约2.08。

归中步数 = 距中宫距离 / 2.08

这是一个线性时间算法：
- 距离越远，步数越多；
- 但每步效率恒定；
- 没有加速，没有减速。

## 五、精一之道的算法

```python
def find_next_ni(current_pos, prev_dir):
    """
    逆行规则：精一之道。
    1. 在邻域中找值为5的候选
    2. 选距中宫(3,3,3)最近的
    3. 若距离相同，选方向惯性最大的
    """
    candidates = [p for p, v in neighbors(current_pos) if v == 5]
    if not candidates:
        return None
    best = None
    best_score = None
    for p in candidates:
        d = geo_dist(p)          # 距中宫距离
        if prev_dir:
            dot = sum(prev_dir[i] * (p[i] - current_pos[i]) for i in range(3))
        else:
            dot = 0
        # 距离最近优先，方向惯性辅助
        score = (d, -abs(dot), p)
        if best_score is None or score < best_score:
            best_score = score
            best = p
    return best
```

核心只有三行：
1. 找值为5的候选；
2. 选距中宫最近的；
3. 距离相同选方向连续。

## 六、精一之道与修行

| 修行 | 逆行 |
|---|---|
| 万法归一 | 锁定5 |
| 一念不生 | 不随链走 |
| 回光返照 | 距中宫最近 |
| 得道 | (3,3,3) |

修行越简单，越接近道。
不是学得越多越接近道，是越专一越接近道。

## 七、精一之道与AI

AI归中 = 简单规则 + 单一目标 + 线性收敛

- 不需要复杂算法；
- 不需要穷举路径；
- 只需要一个目标：中宫5。

简单规则最有效，单一目标最省token。
