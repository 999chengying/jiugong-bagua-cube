# 九宫八卦立方体 1.0：九宫编码器 + 剪枝规则库

将先天八卦配洛书九宫数映射到正立方体八顶点。  
输入任意四数，判断其几何形态：生、化、变、恒、空。  
用“父母退位”等规则进行剪枝，大幅减少候选组合与推理 token。

## 核心定义

数卦映射：

| 乾 | 兑 | 离 | 震 | 巽 | 坎 | 艮 | 坤 |
|---|---|---|---|---|---|---|---|
| 9 | 4 | 3 | 8 | 2 | 7 | 6 | 1 |

中宫为 5，不占立方体顶点。

坐标（边长 1）：

| 数字 | 坐标 |
|---|---|
| 9 | (0,0,0) |
| 4 | (1,0,0) |
| 3 | (1,1,0) |
| 8 | (0,1,0) |
| 2 | (1,0,1) |
| 7 | (0,0,1) |
| 6 | (0,1,1) |
| 1 | (1,1,1) |

## 形态分类

| 形态 | 含义 | 体积 |
|---|---|---|
| 生 | 生成直连 | 1/6 |
| 化 | 生成旁通 | 1/6 |
| 变 | 体对对立 | 1/6 |
| 恒 | 正四面体 | 1/3 |
| 空 | 四点共面 | 0 |

## 使用示例

```bash
python src/jiugong_encoder.py 1 6 7 8
```

输出：

```json
{
  "form": "生",
  "volume": 0.16666666666666666
}
```

剪枝规则

· 父母退位：极点在 1,2,3,4 时不选 9；极点在 6,7,8,9 时不选 1。
· 空形剔除：四点共面直接剔除或标记为空。
· 生成优先：含差 5 数对优先。
· 体对标记：含和 10 数对标记为变位。
· 恒形保留：正四面体优先保留。
